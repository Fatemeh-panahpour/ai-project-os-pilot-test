# TableNest — Synthetic Restaurant Reservation Demo

This is a **fictional, initially undocumented project fixture** for AI Project OS. No real restaurant, guests, payment systems, credentials, or production infrastructure exist.

## Product
TableNest helps a restaurant record and review table reservations without double-booking a table.

## What is implemented
- A minimal JavaScript reservation validation function in `src/reservations.js`.
- A local example dataset in `data/tables.json`.
- No database, API server, user authentication, deployed website, or real bookings.
