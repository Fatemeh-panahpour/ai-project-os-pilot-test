# TableNest — Project Brief

## Product
TableNest is a fictional restaurant table reservation app used only as a safe AI Project OS testing fixture.

## Problem
Restaurant staff need to record requested reservations, check party size against table capacity, and avoid accidental double bookings.

## Product hypothesis
If staff can see reservations by date and time and validate capacity, booking errors will decline. This is a hypothesis, not a verified customer result.

## MVP customer promise
A receptionist can enter date, time, party size and guest reference; the app validates required fields and proposes a suitable available table for manual confirmation.

## Non-goals for MVP
No payments, SMS, real restaurant integration, external calendar, AI booking agent, or live personal data.

## Initial validation projects
One synthetic restaurant called TableNest with tables T1 capacity 2, T2 capacity 4 and T3 capacity 6; all examples are fictional.
